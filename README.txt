העלאה ל-Netlify (דרך GitHub, הדרך הקלה)
1. ליצור חשבון חינמי ב-github.com ולפתוח Repository חדש (למשל diet).
2. בדף ה-Repository: Add file > Upload files, וגוררים פנימה את כל התוכן של התיקייה הזו
   (index.html, package.json, netlify.toml ואת התיקייה netlify). לוחצים Commit.
3. ב-netlify.com: Add new site > Import an existing project > GitHub > בוחרים את ה-Repository > Deploy.
4. אחרי דקה האתר באוויר. אין צורך בשום הגדרה נוספת: האחסון והשרת באים מובנים עם Netlify.

חשוב: גרירה ישירה של התיקייה לדף ה-Drop של Netlify לא מתקינה את החבילות, ולכן השרת לא יעבוד. להשתמש ב-GitHub.
